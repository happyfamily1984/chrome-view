# 크롬뷰

갤럭시에서 Chrome을 쓰다가 인증 앱·문자 등 다른 앱을 다녀오면 페이지가 처음으로 돌아가는 문제를
줄여 주는 Chrome 보조 앱입니다. 웹 페이지·로그인·메뉴는 모두 **실제 Chrome**을 그대로 쓰고,
크롬뷰는 백그라운드에서 Chrome이 정리되지 않게 붙잡아 두는 일만 합니다.

## 동작 방식

- 크롬뷰 아이콘을 누르면 유지 서비스를 켜고 곧바로 Chrome을 실행합니다.
- 유지 서비스는 알림을 띄운 포그라운드 서비스로, Chrome이 제공하는 서비스(Custom Tabs)에 연결해 둡니다.
  안드로이드는 연결된 앱의 중요도를 올려 주기 때문에 Chrome이 '화면에 없는 앱'으로 정리되지 않습니다.
- 크롬뷰를 기본 브라우저로 지정하면, 다른 앱에서 링크를 누를 때 유지를 켠 뒤 Chrome으로 넘깁니다.
- 폰을 켜면 유지 서비스가 자동으로 시작되고, Chrome과의 연결이 끊기면 스스로 다시 연결합니다.
- 설정 화면은 알림을 누르거나 아이콘을 길게 눌러 '크롬뷰 설정'으로 엽니다.
- 설정 화면에서 뒤로가기를 누르면 "앱을 종료하겠습니까?"를 묻고, "예"를 누르면 유지도 함께 끕니다.

## 한계

안드로이드는 다른 앱의 내부까지 제어하게 해 주지 않습니다. 크롬뷰는 Chrome 앱 자체가 정리되는 것은
막지만, 메모리가 매우 부족할 때 Chrome이 스스로 안 보이는 탭을 내리는 것까지는 막지 못합니다.

## 설치

`dist/chromeview.apk` 를 폰에 내려받아 설치합니다. 처음 실행 때 안내에 따라
크롬뷰와 Chrome 모두 배터리를 '제한 없음'으로 두고 알림을 허용해 주세요.

## 빌드

```
./gradlew assembleRelease
```
