# 크롬뷰

갤럭시에서 인증을 신청하고 인증 앱·문자 등 다른 앱을 다녀오면 페이지가 처음으로 돌아가 다시
인증해야 하는 문제를 막는 브라우저 보조 앱입니다.

## 동작 방식

- **크롬뷰 고정 창(기본)**: 페이지를 크롬뷰 안에서 직접 엽니다. 탭을 화면이 아닌 앱 프로세스에 묶어 두고,
  알림을 띄운 포그라운드 서비스로 그 프로세스를 살려 두기 때문에 다른 앱을 다녀와도 페이지가
  다시 불러와지지 않습니다. 로그인 팝업, 인증 앱 호출(intent://), 파일 첨부, 카메라 인증을 지원합니다.
- **Chrome으로 열기(설정에서 전환)**: 아이콘과 링크를 Chrome 앱으로 넘기고, Chrome 프로세스의 우선순위만
  올려 둡니다. Chrome 안의 탭은 Chrome이 스스로 내릴 수 있어 유지가 보장되지 않습니다.
- 크롬뷰를 기본 브라우저로 지정하면 다른 앱의 링크도 위 방식대로 엽니다.
  다른 앱의 '공유 → 크롬뷰'는 항상 고정 창에서 엽니다.
- 폰을 켜면 유지 서비스가 자동으로 시작됩니다.
- 시작 화면: 마지막으로 보던 탭, 없으면 시작 페이지(기본 네이버, 설정에서 변경)를 엽니다.
  홈 버튼은 Chrome처럼 지금 탭에서 시작 페이지를 엽니다.
- 탭 목록·즐겨찾기(메뉴) 화면은 탭 개수 버튼이나 ⋮ → '탭 목록·즐겨찾기'로만 엽니다.
- 시크릿 탭(⋮ → 새 시크릿 탭): 방문 기록과 탭을 남기지 않고, 쿠키·사이트 데이터를 일반 탭과 따로 쓰며
  마지막 시크릿 탭을 닫으면 지웁니다. Android 시스템 WebView가 오래된 폰에서는 쿠키가 분리되지 않습니다.
- 영상 백그라운드 재생(설정에서 끄기 가능): 페이지가 '화면에서 가려졌다'는 신호를 받지 못하게 해서,
  크롬뷰를 뒤로 보내거나 화면을 꺼도 영상 소리가 계속 나옵니다.
- 뒤로가기: 페이지 뒤로 → 팝업이면 원래 탭으로 → 다른 앱에서 넘어온 탭이면 탭을 닫고 그 앱으로.
  더 돌아갈 곳이 없으면 "앱을 종료하겠습니까?"를 묻습니다. 메뉴 화면에서는 보던 페이지로 돌아갑니다.
  종료해도 탭과 로그인 정보는 저장되어 다음 실행 때 되살아납니다(시크릿 탭 제외).

## Chrome 정보 쓰기

안드로이드는 다른 앱이 Chrome의 데이터를 직접 읽지 못하게 막습니다. 그래서 다음 방식으로 이어 씁니다.

- **아이디·비밀번호·주소 자동 입력**: 폰의 자동 완성 서비스를 Google로 두면 Chrome이 쓰는 것과 같은
  Google 비밀번호 관리자가 크롬뷰에도 제안합니다. 설정 화면에서 바로 열 수 있습니다.
- **북마크**: PC Chrome이나 Google 테이크아웃에서 내보낸 북마크 .html 파일을 즐겨찾기로 가져옵니다.
- **주소창 자동완성**: 즐겨찾기와 크롬뷰 방문 기록에서 제안합니다.
- Chrome의 로그인 상태(쿠키)와 방문 기록은 가져올 수 없습니다.

## 알아 둘 점

- 고정 창은 Chrome과 로그인 정보를 공유하지 않습니다. 사이트마다 처음 한 번은 다시 로그인해야 합니다.
- 구글 계정 로그인처럼 앱 내 브라우저를 막는 일부 사이트는 고정 창에서 로그인이 거부될 수 있습니다.

## 설치

`dist/chromeview.apk` 를 폰에 내려받아 설치합니다. 처음 실행 때 안내에 따라
크롬뷰 배터리를 '제한 없음'으로 두고 알림을 허용해 주세요.

## 빌드

```
./gradlew assembleRelease
```
